# POO2 - Roteiro 03 (JSON com Newtonsoft.Json)

| Exercicio | Projeto | Tecnica |
|---|---|---|
| 1 | Exercicio01 | Serializar objeto Livro para JSON |
| 2 | Exercicio02 | Desserializar aluno.json |
| 3 | Exercicio03 | Gravar e ler lista de Carro em JSON |
| 4 | Exercicio04 | Alterar a Porta de uma configuracao com JObject |
| 5 | Exercicio05 | Cadastro de produtos (partes 1 a 6) |

Exercicio05: product_name e product_price (JsonProperty), CodigoInterno fora do JSON (JsonIgnore), ordem das propriedades (Order), campos null ignorados (NullValueHandling.Ignore) e Nome/Preco obrigatorios na desserializacao (Required.Always).

Para executar: `dotnet run --project Exercicio01` (troque pelo numero desejado). Os pacotes NuGet sao restaurados automaticamente.
