# POO2 - Roteiro 04 (JSON / API / Arquitetura)

Projeto PokeApi consumindo a PokeAPI (https://pokeapi.co).

| Exercicio | Onde |
|---|---|
| 1 | Models/Pokemon.cs (Name, Height, Weight) e chamada a API |
| 2 | Services/PokemonService.cs, metodo BuscarPokemon(string nome) |
| 3 | Program.cs pede o nome, chama BuscarPokemon e exibe |
| 4 | Program.cs exibe os dados formatados |
| 5 | Pokemon.cs com Id e BaseExperience |
| 6 | PokemonService.BuscarPokemonAleatorio() (ids de 1 a 1025) |

Para executar: `dotnet run --project PokeApi` (precisa de internet).
